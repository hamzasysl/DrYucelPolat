Hasta yorumu fotoğrafları
-------------------------
Dosya adları config/testimonials.php içindeki 'photos' dizisiyle eşleşir:

  yorum-1.webp                          → 1. yorum (varis ameliyatı)
  yorum-2a.webp / -2b / -2c             → 2. yorum (kaydırmalı galeri, 3 foto)
  yorum-3.webp                          → 3. yorum (Züleyha Akay — lipödem)
  yorum-4.webp                          → 4. yorum (İngiltere'den hasta yakını)

Bir yoruma birden fazla fotoğraf eklemek için config'teki 'photos' dizisine
dosya adını eklemek yeterli — kart otomatik olarak kaydırmalı galeriye döner.
Dosya yoksa kart fotoğrafsız görünür, hata vermez.
Ziyaretçi fotoğrafa tıklayınca tam ekran büyür (lightbox).

Önerilen: dikey/kare kadraj, yüksekliği ~1200 px, .webp (kalite 80-85)
